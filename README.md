# Knowledge Circle — GEI Discovery Prototype

A live, dependency-free prototype inspired by the current GEI / visual-thinking discussion: represent thinkers as nodes, relationships as edges, and unexplored edges as candidate discovery space.

## What this tests

- Complete-graph framing: every pair can be examined.
- Seeded historical relationships versus unexplored relationships.
- Interactive node inspection.
- Deterministic unexplored-edge selection.
- A discovery loop: **map → question → contradiction → explore → simulate → discover**.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Research direction

The next experimental layer should replace the hand-seeded graph with extracted claims from books/papers, typed relationships, contradiction scoring, provenance, and reproducible hypothesis evaluation.
